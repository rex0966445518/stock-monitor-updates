## v0.1.5 日經讀取修正

日經改以隔離的內嵌網頁自動讀取公開報價，支援載入後的Pinia狀態；失敗才退回HTTP。已開啟來源頁時，頁面讀到的報價可在返回看板後直接帶入，不依賴原HTTP請求。僅快取驗證成功的報價。首次可能需數十秒，其他市場先到先填。

同時修正台指日盤資料重置／缺少結算價後，整個夜盤日期被擋住的情況。夜盤開盤與參考價可獨立使用，前一般盤收盤仍須核對。

日經約20分鐘延遲，未有獨立夜盤開盤價時明示改用前結算價；韓股為第三方1分K，延遲未知。日韓兩年歷史仍待補，統計只採有歷史資料的市場，不補造結果。

已通過來源頁狀態讀取、Android相容JSON快照解析、來源頁返回回填與日盤重置案例檢查。**未在實體Android裝置驗證自動WebView載入**。更新前會驗證大小、SHA-256、套件、版本與簽章。
