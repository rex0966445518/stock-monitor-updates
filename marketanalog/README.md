# 跨市歷史比對 Android v0.1.9

已安裝v0.1.2以上可按首頁「一鍵更新」。同套件同簽章覆蓋，請保留原App資料。

v0.1.9：逐日預測改為直式簡表，只需上下滑動。點日期仍可查看原始訊號與相似日；已保存回測會自動使用新排版。\n\n日經擴充至179筆獨立夜盤（2026/1/26～11/2，JPX官方日報）；保留9個假日合併資料缺口。嘗試更早15個月索引均HTTP404，完整兩年仍未取得。

韓股分兩種來源，請在「自動回測／韓股夜盤比較基準」明確選擇：
- 收盤−前日盤參考價（加長版，預設）：157筆，2026/3/14～11/4，第三方Chartlog的夜盤收盤及報告漲跌點。沒有夜盤開盤價、沒有逐日限月，不虛構開盤，另存KRX200_REF。
- 收盤−夜盤開盤：57筆，2026/8/7～11/4，公開LS來源日夜盤交叉核對，202612固定限月，較早日期非當時近月。

修正遇到日經缺資料便不檢查韓股的問題，現在四市場各自列出可用訊號。舊本機快照與新內建歷史合併，保留新增日期與已知缺口。逐日紀錄依日期新到舊顯示，每個日期一張直式簡表，四市場點數兩欄排列，預測／實際／正負面與命中狀態直接顯示，無需左右滑動；新增共同日期摘要及一鍵套用區間，升級後請重新開始回測，上次報告不自動改寫。

加長版共有135個共同訊號台股日期（2026/3/16～11/2）。固定預設參數回測2026/5/1～11/2，124台股紀錄日中98日有效、65日命中，正負面66.33%，同98日全猜負面59.18%。開盤基準是另一份較短樣本，不能直接用新舊命中率宣稱改善。不是完整兩年、不是實盤或未來保證。資料是事後OHLC／收盤變化重建，來源可能修訂。
