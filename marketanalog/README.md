# 跨市歷史比對 Android v0.1.6

[下載最新版 APK](https://github.com/rex0966445518/stock-monitor-updates/raw/refs/heads/main/marketanalog/MarketAnalog-latest.apk)

已安裝 v0.1.2 以上可按首頁「一鍵更新」。同套件、同簽章覆蓋安裝；請保留原App資料。

新增「自動回測」分頁：設定台股日期，逐日使用09:00前訊號，與更早已收盤的歷史相似日預測，再比較當日真實結果。開低走高為正面，開高走低及平盤為負面；以收盤對開盤分類。顯示逐日紀錄、命中率、資料覆蓋、基準比較，可停止、保存及匯出JSON。

開始時更新美股、台股與最近兩個月台指夜盤，保留舊資料。四市場需要日韓真正夜盤歷史，目前需匯入或設定相容授權歷史服務；缺資料會跳過，不會偷偷降級。可明確選「美股＋台指」兩市場模式先回測。歷史命中率不保證未來走向。

Android 8.0+；套件 tw.rex.marketanalog。日經即時頁仍為約20分鐘延遲來源。已完成引擎／瀏覽器／APK簽章驗證，未實體Android驗證。
