# v0.1.21：自動機器人探查

新增一級入口「機器人」：勾選是每組必選，未勾選的條件由機器人加入或排除，跑完全部非空組合。九項無必選為511組，2項必選為128組，9項全必選只有1組。每輪先更新候選資料再固定快照，本機逐組回測。

每個完成組合與續查游標原子保存，暫停／離開App／強制關閉後可續查，未完成那組會重算，完成組不重複計入。前十名由探索期成績選出，再核對保留驗證期，驗證不參與排名；明示樣本、涵蓋、基準及不足標記。歷史名次不保證未來成功率。

前景持續模式預設每15分鐘檢查資料，跨日自動延長日期；無新資料等待，有新資料另開新輪，舊輪固定快照與排行保留。不宣稱App被關閉後仍在背景運算。可匯出本輪記錄與快照、查看逐日驗證並套用組合到手動預測。

[下載 MarketAnalog-v0.1.21.apk](MarketAnalog-v0.1.21.apk) · versionCode22，沿用原簽章。測試已實際跑完511組及十名保留期；另驗證暫停／重開／續查、不重複記錄、儲存失敗恢復、準備中取消、跨日、無新資料等待、新資料另開輪與手機版面。
