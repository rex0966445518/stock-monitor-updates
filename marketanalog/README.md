# 跨市歷史比對 · Android

目前版本：**v0.1.2**（versionCode 3）。Android 8.0以上。

[下載最新版 APK](https://github.com/rex0966445518/stock-monitor-updates/raw/refs/heads/main/marketanalog/MarketAnalog-latest.apk)

先安裝此版本，即可在首頁使用「一鍵更新」。舊版沒有按鈕時，請先下載此APK覆蓋安裝，無需先解除安裝。未來按一鍵更新即可檢查版本、下載及開啟Android安裝確認畫面；首次需依系統提示允許安裝更新。

新功能：下載進度、取消、重試與最新版提示；安裝前驗證檔案大小、SHA-256、套件、版本與簽章。

此App另有歷史跨市場比對及5秒行情輪詢控制。**日韓台夜盤秒級數值仍需自有的相容授權行情服務**，並非安裝後即可取得四市場即時資料。

更新紀錄與檔案校驗資訊見 latest.json。這個目錄不含簽章私鑰或API憑證。
