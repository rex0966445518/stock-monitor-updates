# v0.4.99: 籌碼K線 → Gemini 圖像分析（第一階段）

## 已實作
- 「條件與工具」新增「Gemini 籌碼 AI 分析」入口。
- 使用者輸入 4–6 位股號，沿用既有籌碼K線 App 搜尋輔助。
- 使用 Android MediaProjection 由使用者**每次明確授權**，啟動可見的前景服務，在籌碼K線畫面就緒後擷取**一張**截圖。
- 完成後在通知列提示，返回本 App 預覽截圖、確認股號；使用者點擊「分享截圖給 Google Gemini」才打開 Android 分享選單。
- 包含「從相簿匯入截圖」備援、股市研究的證據導向提示詞，以及「複製分析指令」。
- 截圖儲存在本機 app cache 中，最多保留 20 張；可一鍵刪除目前截圖。沒有靜默上傳或自動下單。

## 手機上使用
1. 先安裝並登入 CMoney 籌碼K線，確定帳號有權檢視需要的資訊。
2. 在離職神器「條件與工具」找到 Gemini 籌碼 AI 分析，輸入股票代號。
3. 點選授權擷取。當 Android 出現分享選擇時，選**整個螢幕**或**籌碼K線應用程式視窗**，不是離職神器本身。
4. 本 App 將開啟籌碼K線並嘗試搜尋股號，稍後通知列顯示截圖結果。點擊通知預覽。
5. 檢查是否拍到正確股票。按下分享，從系統分享選單選 Gemini；如 Gemini 未接收文字提示，將已複製的指令貼入對話後送出。

## 限制
- 這是**單檔、單張圖**的可操作 MVP。AI 回答由使用者在 Gemini App 中觀看，不會自動回寫到離職神器。
- 全市場、跨個股批次擷取、跨籌碼頁籤巡覽，以及 Gemini API 直接回傳結構化分析，**尚未實作**。需要 CMoney 授權的資料 API（或確認符合使用條款的其他正式方式）及 Gemini API 安全授權。
- 現有籌碼K線 UI 可變動；既有無障礙搜尋輔助可能失敗。捕捉前使用者應自行確認畫面，截圖完必須預覽。
- Android 14+ 的畫面分享需要每個工作階段授權；截圖受系統、OEM、螢幕保護 FLAG_SECURE 及通知權限等限制，不能繞過。
- 不把圖片中看不見的主力成本、外資、投信、券商分點等數字臆測為事實。
- 「單張圖片 → Gemini」是研究工具，不提供證實的勝率或投資獲利承諾。

## 第二階段建議
串接 CMoney 數據貓頭鷹等**已授權的欄位**，由 ABCDEF 篩選輸出候選股清單，在後端以每日差異資料提交 Gemini API（API key 保存在 Cloud Run / Secret Manager，不能放進公開 APK），回傳有日期與出處的 JSON 報告卡，建立研究分數與回測。用數字來源交叉核對圖片 OCR，避免 Gemini 誤讀，控制成本與速度。
