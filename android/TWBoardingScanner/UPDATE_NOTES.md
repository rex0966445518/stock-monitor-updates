AI-離職神器 v0.4.92

主頁新增「掃描資料夾」入口，每次完成掃描都獨立保存當次日期時間、條件快照及結果。完整結果包含入選、待查核、未通過卡片與原始證據；切換頁面、系統重建主頁或重開 App 都會載入最近完成的一次掃描。讀取與壓縮在背景進行，完整結果分段儲存，避免大量資料超過 SQLite CursorWindow 限制。

資料夾直接列出當次啟用類別及勾選條件，保留詳細條件快照、股票及排名。後續修改篩選設定不改寫已完成掃描的顯示結果；重新掃描才套用新條件。舊版掃描資料夾與日曆日誌繼續保留，舊紀錄沒有完整快照時不重新推算入選狀態。

新增按掃描批次追蹤模擬交易淨損益，分列已實現、未實現與持倉報價時間。批次 ID 隨候選、買入持倉及賣出紀錄永久保存，不會把同一股票後續掃描或其他批次的盈虧混在一起。尚未交易顯示「總盈利 0 元 · 尚未交易」，舊交易沒有批次 ID 時標示未關聯。實際交易不因還原主頁而自動啟動。

新增主頁重建還原、完整待查核證據往返、空掃描保留、大快照分段、舊資料庫升級、跨批次買賣及帳本相容性測試。
