# v0.4.7 財務查核

A/B/C 共用七項選填條件，各區獨立儲存；保留原 EPS／營收及技術條件。新增條件預設關閉。

- 近四季 EPS 合計 > 0。
- 連續四季 EPS 每季 > 0。
- 近四季 EPS 合計大於前四季，且前四季合計 > 0。
- 最近三個完整年度 EPS 均為正且逐年增加。
- 最近五個完整年度 EPS 均為正且逐年增加。
- 最新列示期間營業利益率 > 0；不代表可排除業外收入。
- 最新列示期間營業現金流 > 0。HiStock 頁面未明示單季/累計及單位，故只取符號、不加總期間、不計算自由現金流。

來源：HiStock 每股盈餘、現金流量表、利潤比率。解析表頭而非固定欄位位置，校驗股票代號；EPS 只讀 Q1-Q4，年度總計僅供完整年度比較。各財務指標独立標示期間。EPS 最新季/現金流/利益率期間距查核日超過六個月或在未來，標待查核。年度須連續完整，4月起須含上一年度。

技術條件通過的候選股才自動讀取財報，逐檔串行、請求間隔至少一秒；成功表格快取24小時，失敗5分鐘冷卻，403/429對來源冷卻30分鐘。卡片提供手動查核、來源連結及錯誤原因。讀取不會繞過登入、拒絕存取或驗證。未勾選缺資料不阻擋；勾選未通過/缺資料不入選。財報查核時間與日K日期不同，不是歷史回測。

限制：開發環境對 HiStock 實際 HTTP 測試返回403，無法驗證即時 HTML 整合成功。解析測試使用依已讀頁面表頭/數值建構的HTML測試資料，不是實站原始HTML；手機端存取及未見過的版面仍須驗證。程式不內建3661等個股財務數值作為掃描資料。產業EPS固定範圍不是通用門檻，不以其評定優劣。金融業營業現金流應依業務性質另外解讀。
