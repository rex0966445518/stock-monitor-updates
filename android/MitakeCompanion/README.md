# 漲停雷達手機版 v0.1.6 · 個人股倉與 Gemini 圖片分析

- 主頁新增「個人股倉分析」：可匯入持股截圖，在本機以內建中文字模型辨識；可再用 Gemini 辨識股號、股名、股數、平均成本及截圖現價，逐筆核對後才寫入股倉。股數固定以股為單位，未知欄位留空，不推估。
- 每檔持股可修改、刪除，顯示未扣交易費用的紀錄損益；價格為使用者核對的截圖紀錄，非即時行情。
- 每次分析建立獨立圖片組，可手動匯入、更換並預覽「K線、籌碼日報、法人、多空、主力、大戶」六類圖片，支援部分資料分析並列出缺頁；圖片儲存時間不是行情日期。
- Gemini 使用個人 API 金鑰及可調整模型（預設 gemini-3.8-flash）。金鑰由 Android Keystore 加密，不寫入URL、不含在APK、不記錄到日誌。只有明確按下傳送，或在本次收集勾選「六頁完成後自動分析」，才向 Google 提交圖片及持股資料；模型可用性、額度和費用依個人帳戶。未設定金鑰仍可用本機股倉及圖片歸檔。
- 分析要求逐圖核對股號、日期及類別，分開列事實與推論，包含持股風險、可見價量與籌碼證據、缺漏資料及失效情境；不補造行情或勝率、不執行交易。Gemini失敗、額度限制、回覆截斷時不偽造結果，不自動重送付費請求。
- 收集前可選「六頁完成後自動傳送Google Gemini分析」，需已設定金鑰。只在六頁全部核對成功後送出；不完整或中止不自動送出。未選時返回預覽後手動送出。相同分析任務不允許重疊請求，降低重複計費風險。
- Android 14以上提供**實驗性**籌碼K線輔助使用收集：由使用者閱讀用途並手動啟用系統權限，再啟動單次指定股號任務。只在 com.cmoney.chipk 讀取明確搜尋欄位及頁籤，核對股號和選取狀態，以指定視窗截圖、本機OCR再次核對股號，再存入本機。浮動停止控制可隨時終止；找不到頁籤、切至其他App、無法核對或禁止截圖時停止／等待逾時，不使用盲點座標、不處理交易。
- 尚未收到使用者操作影片，**第三方實機六頁自動搜尋及擷取尚未驗證**；未暴露文字或選中狀態的畫面無法自動操作，須在籌碼K線手動選股或改用逐頁匯入。這不代表已修好主頁候選卡片直達個股的深層連結。
- 截圖、股倉及分析歷史只存本機私有目錄，不加入電腦掃描快照、不啟用雲端備份。可刪除各筆分析與圖片；送到Google的請求仍依Google API資料條款處理。
- 保留既有簽章，v0.1.1以上可覆蓋升級並保留配對。需自行在股倉Gemini設定輸入金鑰，勿將金鑰貼到聊天。

驗證範圍：CI會執行既有相機、PC連線與通知測試，加上股倉輸入核對、本機圖片匯入及OCR、歷史儲存、無金鑰操作流程。真實Google API回應及真實籌碼K線內部頁面須在設定金鑰與安裝第三方App的手機驗證。

# 漲停雷達 · Android 電腦連動 v0.1.3

- 新增「連線診斷」與立即重連，顯示私人 IP、網路類型、最後成功時間及具體原因。一般 4G／5G 無法直接連區網電腦，外出需私人 VPN。
- 手機主頁新增「一鍵更新」：從官方 GitHub 發布清單找出較新的手機版，顯示下載進度；下載可在背景持續，重開 App 可續查進度。
- 驗證 SHA-256、大小、套件名稱、版本與安裝簽章後才開啟 Android 安裝確認。首次需在系統允許此 App 安裝更新。
- 新增「語音通報」開關、試聽及系統語音設定入口。預設開啟，播報有效新訊號的股名、股號、5/6 或 6/6 及必要檢核狀態。
- 依既有事件序號去重；暫停、無效或超過 15 秒的資料不播報。語音等候佇列有容量及時效限制，排隊時同股升級會替換舊訊號。
- 手機若缺少中文 TTS 語音，設定頁會顯示原因；請下載中文語音。音量跟隨手機媒體音量。
- v0.1.1 可直接覆蓋升級並保留配對；v0.1.0 因舊簽章不同，需先移除再重新配對。電腦端資料不受影響。

使用：手機與電腦同 Wi-Fi，在電腦「進階工具 → 手機連動／配對」啟用後，以手機掃碼。外出使用需自行設定私人 VPN。電腦需保持開機與掃描，手機需允許背景連線。

5/6、6/6 是觀察訊號，不是買進指令。手機語音、背景接收與安裝流程仍需各廠牌實機確認。
