# v0.1.1 QR 掃描修正

安裝：v0.1.0 的發布簽章與固定測試金鑰不同，請先移除舊手機版，再安裝 v0.1.1 並重新配對。v0.1.1 起明確指定固定測試簽章。

- 補齊 AndroidX core 相機權限依賴，並檢查 APK 中實際定義的必要類別。
- 開啟 QR 掃描前先要求相機權限；拒絕後顯示手動配對方式。
- 補上掃描啟動例外處理；不記錄配對憑證。
- 發布流程新增 Android 16 模擬器的兩個掃描入口、拒絕權限、允許相機及返回主頁驗證。
- 尚待使用者實機相機與電腦 QR 碼驗證。

# 漲停雷達 · Android 電腦連動 v0.1.1

與漲停板探測器 Windows v0.3.63 配對，手機顯示電腦OCR觀察結果；此APK是獨立的電腦連動App。

1. 更新電腦版，開啟「進階工具 → 手機連動／配對 → 啟用／顯示配對碼」。Windows防火牆如有提示，允許私人網路。
2. 手機與電腦接同Wi-Fi。安裝APK，開啟「掃描電腦配對碼」，確認連線並允許通知。
3. 電腦保持開機，開啟全部六項條件後按F8掃描。手機每3秒接收一次快照與事件，實際通知還包含OCR掃描耗時。
4. 外出連線可使用自行設定的私人VPN；在電腦配對頁選其私人IPv4位址後重新配對。此版不附雲端轉送服務，不需要公開路由器連接埠。

- 5/6、6/6升級通知，個股通知由電腦冷卻時間去重；6/6基礎條件與必要檢核通過分別標示，不代表買進指令。
- 手機列表保留當日曾達條件的後續轉弱紀錄。逾15秒、暫停、離線的舊快照不算即時候選；手機不為過期或待複查資料新增提醒。
- 連線中使用可見的前景服務通知，可隨時停止。手機系統省電、休眠、強制停止或網路隔離可能延遲／阻止通知；需要在實機確認背景接收。
- 配對碼是私人網路讀取憑證；電腦只提供唯讀快照，沒有交易或遠端控制功能。可隨時停止或重設配對碼。
- 本版為GitHub直接安裝的固定測試簽章APK；不是Google Play正式上架版本。更新前可保留既有獨立選股App，兩者套件不同。

驗證：Robolectric介面、私網配對檢查、實際HTTP協定與通知條件測試、Android Lint、APK簽章與公開下載位元組比對。尚未在使用者實體手機與三竹設備做端到端測試。

Android通知服務依官方文件實作：[前景服務類型](https://developer.android.com/develop/background-work/services/fgs/service-types)。
