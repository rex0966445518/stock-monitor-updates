# 股票小助理 v1.0.13
雷允澤設計

[下載 Android 安裝檔](releases/StockFloat-v1.0.13.apk)

修正台股報價來源與行情時間：優先證交所 MIS，個股備援為鉅亨、Yahoo 網頁及圖表。各來源均檢查行情時間；盤中超過15秒的價格不再顯示、播報或觸發提醒。下載成功不代表行情更新。收盤時間只提供最近收盤參考，不觸發台股到價提醒。聯發科2454統一顯示中文簡稱。輕點浮窗可查看來源與行情時間。

Android 8 以上；可覆蓋安裝舊版。既有使用者可按 App 內「檢查新版本」。已通過編譯、簽章、八組回歸測試與 Java 取價流程連線測試；取得聯發科報價時行情距取得時間約3秒。尚未進行 Android 實機券商同步比對，公開來源仍可能延遲、限流或無報價。

若 LINE 內建瀏覽器無法下載，請以 Chrome 開啟此頁，點選安裝檔後使用下載圖示。
