三色數值監視器 v0.3.0 — 作者雷允澤

安裝：雙擊 NineMonitor-Setup.exe，確認安裝。會建立桌面／開始功能表捷徑，並可從 Windows 已安裝的應用程式移除。支援 Windows 10／11 x64，不需另裝 Python。

使用：
1. 在電腦顯示目標數字，分別按「框選橘色／粉紅色／白色」，各框一個數字。不要框其他文字和數字。
2. 顏色與預設不同時，按「點取筆畫顏色」，點該數字筆畫中央。ESC 可取消。也可恢復預設色。
3. 按「單次辨識測試」，核對三個值與 OCR 原文。測試不寫正式紀錄、不發門檻警報。
4. 各自輸入三個門檻。警報條件為：橘色＞橘色門檻 AND 粉紅色＞粉紅門檻 AND 白色＞白色門檻。相等不算超過，缺任何一項不報警。
5. 取樣預設每 60 秒一次，可改為 5～3600 秒。按「開始監視」後預設最小化。按 ESC、停止按鈕或右下角圖示可停止。
6. 三個值來自同一次螢幕截圖。持續達標只提醒一次，三項有效且離開條件後再同時達標才重報。缺值不補零、不沿用前次值、不當成重報的重設條件。
7. 按「測試語音」確認聲音。語音清單可選 Windows 已安裝且 System.Speech 可使用的語音。優先中文；沒有中文會用英文播報。完全沒有語音引擎時顯示原因，仍可發音效與通知。
8.「開啟測試數字」可開一個真正的三色測試視窗，自行調整數字，用來驗證取色和 OCR，不是直接餵值到監視器。
9.「一鍵更新」停止監視、檢查專屬更新通道，下載新版本並驗證 SHA-256，再安裝與重啟。更新保留設定、選框、色彩校正與歷史，不會自動重新開始掃描。

注意：
- 目標區域必須保持可見、解鎖；不要移動、遮擋、捲動畫面。螢幕配置改變會要求重新框選。
- 每次取樣間短暫觸及門檻可能漏報；可依需要調低間隔。
- OCR 可能將相似數字辨錯，首次請用真實畫面核對結果。只框一個數字、排除同色標籤和格線，可提高可靠度。
- 白色字的亮度、粉紅／橘色的實際色相可能不同，必要時請取色校正。若同色格線也在框內，請縮小框選。
- 音量、靜音、勿擾、語音元件由 Windows 控制。先測試語音確認可用。
- 使用 Windows 本機 OCR；沒有可用 OCR 語言時會顯示錯誤，請安裝英文文字辨識元件。沒有虛構示範數據。
- 本機截圖只供辨識，暫存黑白遮罩用完即刪，不上傳影像。強制終止可能留下暫存遮罩檔。
- 設定與記錄在 %LOCALAPPDATA%\NineMonitor\Data，升級與解除安裝保留此資料。CSV 可匯出所有三色紀錄。
- 安裝位置為 %LOCALAPPDATA%\NineMonitor\App；不需管理員權限，不永久修改執行原則。

【v0.3.0 自動右移並連續偵測】
- 三色區域與門檻設定好後，按上方「自動右移 5 次／秒」。程式最小化；3 秒內點選要移動的目標圖表。
- 倒數後固定當前目標視窗，每 200 毫秒排程一次完整向右鍵按下／放開，目標速率每秒 5 次。
- 鍵盤排程在獨立執行緒，OCR 進行中也持續排程；系統忙碌時不會補發一大串積欠按鍵。
- 自動模式不使用原本的每分鐘間隔；每輪 OCR 完成就接下一次取樣，持續記錄、檢查三項共同門檻並語音提醒。
- 辨識速度依電腦與字體而異，不保證每次右移都有一筆紀錄。每筆使用實際取樣時間（毫秒）、取樣開始時已送出的按鍵次數與獨立樣本 ID，不能把按鍵次數當成完整逐格資料。
- 每筆三色仍來自同一次螢幕截圖，不沿用舊值。自動模式紀錄包含 Mode=AutoRight5Hz、RightPresses、SampleId，CSV 匯出一併保留。
- ESC、停止按鈕、切換前景視窗、關閉／最小化目標，均停止按鍵與監視。Ctrl／Shift／Alt／Win 按住時也停止，避免變成其他快捷鍵。
- 右鍵需由目前的目標程式接收；選到圖表後請不要點同一視窗內其他文字輸入框，否則同一個視窗可能把右鍵解讀為移動文字游標。
- 程式不會搶回已切換的焦點；再開始需重新按按鈕並選目標。目標若以較高權限執行或不接受模擬輸入，會停止並顯示原因，不繞過 Windows 限制。
-「開始監視」原按鈕仍保留定時間隔模式；只有新按鈕會連按向右鍵並連續取樣。
