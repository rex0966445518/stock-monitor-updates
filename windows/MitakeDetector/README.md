## v0.3.66：股名資料庫與四位股號

股名資料庫位於使用者資料目錄的 `stock-names.sqlite3`。既有已驗證 `stock-names.json` 自動遷移；資料庫保存股號、中文／合法股名、信心、來源和學習時間。首次遇到四位股號即排入批次補名，不再由5/6門檻決定是否學習。每批最多32檔，尚未辨識成功者保留待補；成功者之後按股號查記憶，不重跑名稱OCR。全頁數字恢復時仍可能處理包含名稱的原圖，正常數字快掃只補讀未知名稱。確認名稱不被後來不同OCR結果覆蓋，可用進階工具清除股名記憶重新學習。這是本機學習字典，並非已下載全市場官方證券名冊。

只接受恰好四位ASCII數字。快掃先讀股號，長股號／帶字母代號不讀其數字格、不學名稱、不加入結果，但保留作為捲動重疊錨點。純排除頁面繼續往下捲動；恢復辨識路徑可能辨識整欄後再排除。歷史資料不刪除。0050等四位ETF仍保留，不能把此規則稱為完整ETF排除器。

首次遇到新股需要補名時間，記憶累積後才省去重複名稱辨識。價格、成交量與時間仍讀取實際畫面，不從股名資料庫推測行情。

## v0.3.65：09:00–12:50 盤尾緩漲觀察

主頁預設勾選「09:00–12:50盤尾緩漲檢核」。請在09:00前開啟三竹與掃描，保持連續採樣；12:50前為累積階段。原六項條件仍各自計分，此模式是額外必要檢核，未通過時標示「待盤尾檢核」，不發出5/6、6/6語音、公告或手機事件。既有5/6日誌仍保留基礎符合紀錄與未通過原因，不等於通過緩漲檢核。

初始門檻（可在「緩漲明細／設定」調整）：首末採樣漲幅1～6%、上漲5分區間占比至少55%、正向價格回歸R²至少0.65、採樣最大回撤不超過1.5%、相鄰5分區間末筆漲幅不超過1%。固定排除單區間貢獻超過總漲幅35%、最後30分鐘貢獻超過40%。不是要求每筆成交都上漲。

資料完整性：09:05前、12:45後都須有有效讀值；46個5分區間預設覆蓋至少80%，最長缺口不超過10分鐘。啟動時自動還原當日資料，午間新啟動且沒有早盤紀錄時標示資料不足。重試載入不會刪除資料；跨日不沿用昨日行情。12:50後持續追蹤，較窗口末筆回落超過回撤門檻時標示轉弱。

每分鐘保留最後有效採樣與當日首筆，5分區間使用末筆；原始掃描資料仍完整留在資料庫。這些是採樣走勢，不是完整逐筆行情，可能漏掉採樣間的急跌。漲幅以首筆採樣為基準，不冒充交易所開盤價。未掃描到的股票／時段不會憑空補出。歷史重播遵循當時資料可用時間，舊設定沒有本模式時維持原行為。

門檻是待回測的啟發式規則，沒有承諾勝率，不能憑量價判定特定大戶吸籌，也不等於安全買點。此更新不改手機端程式。

### 每日資料庫與自動研究（v0.3.56）
正式掃描會將完整解析結果追加到 `%LOCALAPPDATA%\MitakeDetector\observations.sqlite3` 的 `scan_batches`、`scan_quotes`、`scan_configs`；既有 observations 與訊號驗證資料保留。包含不符條件與被引擎略過的讀值、擷取及接收時間、設定、版本、排行、略過原因、無法解析列數。未保留無法解析列的文字或截圖。資料不因暫停、重新開始或更新刪除，磁碟用量會隨使用增加。

進階工具「每日紀錄／重播驗證」可檢視每日筆數、備份完整 SQLite（含 WAL 中已提交資料）及指定日期重播。依原批次到達順序、當時設定與目前程式引擎重建訊號；舊版本引擎規則可能不同。後續價格僅取實際掃描到的300～330秒讀值，缺值不補價；這不是可成交交易績效。

研究服務在程式開啟且啟用時自動補抓18個月官方日線與最近3期官方歷史集保，追蹤清單持久保存，6小時刷新；單次接收前20股，最多100股。歷史已完成月份不重抓；錯誤顯示在研究狀態，不阻塞OCR。研究事實及內容修訂存入 research.sqlite3，並記錄第一次擷取時間，不能把歷史來源日期當成當時已公開時間。

自動優化目前限定日線研究的20日高點突破量倍數（1.5／2／2.5）；不自動修改盤中六條件與進場檢核。至少250個交易日、分開訓練／驗證／60日獨立測試及6日間隔，每期30訊號／10股／15日期以上；驗證與測試淨平均皆超過基準0.5百分點且下側10%分位不退步才套用。模型為次日開盤到第5日收盤，扣0.8百分點成本滑價預留；不可成交鎖價、異常價格及長缺口排除。新資料表現退化回復基準，樣本不足維持參數。持續測試使用全新測試日期，不反覆迎合同一測試區間。

此實驗沒有完整企業行動還原、下市股票母體及產業中性化；追蹤樣本存在選樣與存活偏差。它不能證實大戶吸籌、漲停機率或安全買點。官方日線無法重建歷史盤中委託或5分鐘量速，完整盤中策略需累積實際本地資料後再驗證。


### 5分量速比（v0.3.57）
同股在所有排行共享成交量時間軸，首次需至少觀察10分鐘。倍率是近窗每秒成交量增量除以前窗每秒成交量增量；使用實際觀測點，不插補數值。優先選接近五分鐘／十分鐘的點；兩窗各限180～360秒、總長480～720秒。若任一窗偏離300秒超過15秒，表格顯示「約」，原因欄顯示實際秒數；量速篩選仍以此按秒數標準化的比值比較。它不是歷史20日同時段量比，也不是預估量增。

未滿10分鐘顯示累積進度；無合格時間點顯示「採樣缺口／需回訪」，前窗成交量為零顯示「前窗無成交量」，而前窗有量、近窗無量顯示0.00。回訪超過6分鐘可能無法計算，需要持續較密集掃描同股。暫停／更新可還原共同紀錄，舊版各排行紀錄會合併；新交易日及明確重新開始會重置時間軸。


### 歷史價格時間與掃描輪次
v0.3.57 起，8個歷史股價欄以60秒期間記錄實際擷取價；收到該期間首筆有效讀值才新增時間欄，期間內的同股較新讀值更新原欄。未被掃描的股票留—，沒有新資料不生成空欄。這些是價格時間快照，並非全市場掃描輪次；完整輪次仍需驗證各排行末端後才累計。頂端任務顯示本輪開始時間與已經過時間；斷點接續保留開始時間，耗時包含暫停時間。


### 5/6候選歷史日誌（v0.3.58）
進階工具的月份日曆可查看每天曾達5/6或6/6的股票。需啟用全部六項基礎條件（價格、總量、漲幅、換手率、量速、突破守穩），且判定不是無效／待複查資料，才新建當日候選；進場檢核未通過的5/6仍是觀察紀錄，不是買入指令。入選後持續保存後續觀測與當時條件、來源、版本，轉弱不刪紀錄；待複查數值保留原因但不更新最近有效價格。資料在本地observations.sqlite3的candidate_diary／candidate_diary_events／candidate_diary_configs，不因更新或重新開始刪除。

開啟日誌會背景整理既有scan_quotes完整批次（v0.3.56起），按原設定以目前計數邏輯重建候選紀錄，並保留當時版本；不是重跑當時引擎或補造過去資料。可再次按「整理既有掃描紀錄」增量整理。僅有更早observations而無完整批次的資料不匯入。日誌是掃描觀測，未記錄用戶實際成交及損益。


### 主頁大盤與當日名單（v0.3.59）
標題最右邊每15秒背景查詢 https://mis.twse.com.tw/stock/api/getStockInfo.jsp?ex_ch=tse_t00.tw&json=1&delay=0 ，顯示加權指數、漲跌點數／幅度及來源時間。來源超過90秒或請求失敗會標示非即時／保留前值，無資料時不顯示假值；這是公開網站行情輪詢，不是保證零延遲的專線報價，也不作為選股條件。

底部左側顯示本地日誌中今日曾達5/6或6/6的全部候選，轉弱不移除，過期與不可信讀值顯示待複查，最近有效價不被錯讀覆蓋。雙擊可看日曆明細。訊息日誌移到右下角自動斷行；每日名單不受主表篩選或重新開始影響。跨日切換今日日期，先前名單仍保留在日曆。
