# 三竹盤中轉強偵測器 Windows

Windows 10/11 x64；以使用者目前顯示的排行榜畫面辨識候選訊號。

## 安裝與更新

從 [最新版發布頁](https://github.com/rex0966445518/stock-monitor-updates/releases/tag/mitake-latest) 下載 `MitakeDetector-Setup-v版本.exe`，雙擊安裝。不需要自行安裝 Python 或 OCR 元件。

在偵測器內按「檢查更新／下載安裝」，看到新版後按「下載並安裝新版」。下載完成會核對大小與 SHA-256，再關閉程式、啟動安裝並重新開啟。設定與歷史位於 `%LOCALAPPDATA%\MitakeDetector`，不在程式安裝目錄內。

獨立更新資訊：`https://github.com/rex0966445518/stock-monitor-updates/releases/download/mitake-latest/mitake-update.json`。

## 三竹畫面設定

1. 將可見欄位由左至右排成：股號、股名、成交價、漲幅%、總量（張）、換手率%。股號需獨立欄位。
2. 按「框選排行榜」圈選表格，接著「校正欄位」逐欄點選中心。
3. 設定條件，按「開始實盤」。保持表格可見；移動或縮放後重新校正。
4. 沒有換手率可不勾選該條件，校正時在最後點選右側預留位置。

只偵測可見列，沒有自動翻頁、全市場資料或三竹官方SDK串接。觀測高點為本輪看到的高點；量速比需連續觀測10分鐘。不是漲停保證，不執行交易。需使用者的實際三竹畫面進一步驗證辨識效果。

## 開發與發布

本目錄的來源變更推送到 `main`，會觸發 `.github/workflows/mitake-windows.yml`：

- Windows runner 執行核心與更新驗證測試。
- PyInstaller 編譯 EXE，再執行實際 EXE 的 Tcl/Tk、OCR、資料庫與介面 smoke test。
- Inno Setup 產生免管理員權限的安裝檔，測試安裝、覆蓋更新與保留設定。
- 發布不可變的 `mitake-v版本`，確認下載 SHA-256 後才更新 `mitake-latest` 更新資訊。

發新版先修改 `MitakeDetector.py` 的 VERSION 與 `RELEASE_NOTES.md`，必須使用新版本號。版本發布已存在時，不覆寫該版本安裝檔。

本機開發：`python -m pip install -r requirements.txt`，`python MitakeDetector.py`。
核心測試：`python MitakeDetector.py --self-test`，`python -m unittest -v test_updater`。

## v0.3.0 自動輪切

按「自動輪切設定」，選擇三竹視窗，依序框選排行下拉框、展開選單、資料表格。設定排行清單、每個排行讀取後停留秒數及讀取頁數，先執行「測試輪切一次」確認選單文字辨識與點擊正確。

按「開始自動輪切」後偵測器縮至工作列，滑鼠會用於選單及表格捲動。F8可停止；切至其他視窗、遮住目標、縮放/關閉/最小化目標時停止。視窗尺寸變更後需重新框選。選單標題未確認時不接收該排行讀值。

所有排行的表格欄位需一致，沿用主畫面六欄位置校正。程式使用本機Windows視窗API及OCR，沒有官方行情接入。自動捲動僅覆蓋設定頁數，股號去重，來源排行寫入歷史。

Windows CI會操作獨立的模擬排行選單，驗證實際滑鼠切換、OCR標題及停止行為；實際三竹環境仍需先測試一次。

## F8快捷鍵（v0.3.1）

首次完成自動輪切設定及欄位校正，保留偵測器開啟（可最小化）。將設定的三竹視窗置前，按下並放開F8開始輪切，執行中再按F8停止。長按只執行一次；其他視窗在前景時不啟動。

## 一鍵自動設定（v0.3.2）

只開一個三竹「熱門排行」視窗，保持表頭、股票資料及左上角類目選單可見。按主畫面的「一鍵自動設定」，或將熱門排行置前按F8。程式會最小化自己，尋找表頭與選單、展開清單、自動驗證漲幅排行切換與讀取後儲存；F8首次啟動會繼續執行任務。無法辨識時會停止並保留手動框選入口。設定成功後維持相同視窗尺寸與欄位配置；若改欄位順序，重新自動設定。

名稱可在股號左邊，其他行情欄位可共存。自動模式分欄讀取六個主要欄位；主畫面的手動框選及圖片測試仍使用手動六欄配置。

## 一鍵更新（v0.3.3）

停止任務後按「一鍵更新」，有新版即自動下載、核對大小與SHA-256、安裝並重開。若已是最新版會顯示提示；下載或驗證失敗不啟動安裝。設定與歷史保留。Windows仍可能顯示系統安裝或安全性提示。

## 執行進度（v0.3.6）

F8與一鍵自動設定執行時，熱門排行頂部中央任務列顯示運作時間、階段、排行／頁數、讀取檔數與等待倒數。活動條表示仍在運作，不代表整個任務完成比例。按F8停止或遇錯誤後進度窗關閉，主視窗顯示結果。

勾選「語音提醒」後，開始任務會播報「開始執行掃描」，並提供停止、設定完成及錯誤提示。使用Windows已安裝的語音，優先繁體中文；語音無法播放時記錄原因，不中斷掃描。


## 自適應加速（v0.3.8）

在「自動輪切設定」可關閉自適應加速或清除經驗。預設開啟，成功讀取後將原停留秒數視為上限，逐步縮短到1秒；空資料或不完整資料會重設。經驗保存於設定同目錄的 automation-experience.json。變更視窗尺寸、選單或表格位置會失效重學。只學習選單搜尋路徑與成功次數，不會修改程式、OCR模型或交易條件。完全相同的圖片可重用辨識文字，但不重用行情時間戳。
