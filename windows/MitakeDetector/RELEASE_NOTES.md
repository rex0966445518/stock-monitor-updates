# 三竹盤中轉強偵測器 v0.3.6

- F8任務與一鍵自動設定執行時，畫面最上方顯示任務狀態列與進度。
- 顯示運作時間、目前定位階段、輪次、排行、頁數、讀取檔數與等待倒數。
- 未知總量的定位階段使用活動進度條；持續輪切顯示當輪頁數進度，不假裝是整個任務完成百分比。
- 狀態列置於熱門排行頂部工具列中央，Windows下不搶焦點且滑鼠穿透；停止、失敗或結束後關閉。
- 保留F8開始／停止與一鍵更新。

- 新增可開關的Windows中文語音提醒：F8開始播報「開始執行掃描」，停止、設定完成與錯誤時簡短播報。使用電腦已安裝的語音，優先選擇繁體中文。

- 頂部明確顯示設定步驟1～4，以及切換排行、確認類目、讀取資料和等待等實際工作階段。
