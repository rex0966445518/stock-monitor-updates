三竹盤中轉強偵測器 v0.3.0

- 新增三竹視窗選擇及自動輪切設定：排行下拉框、展開選單、資料表格三區校正。
- 可勾選漲幅排行、估量、預估量增、大單流入/流出/匯集等排行，設定停留秒數與讀取頁數。
- 以OCR尋找選單文字、必要時捲動，再核對切換後的排行名稱才收集資料。
- 可自動向下捲動表格，依股號合併本次各頁讀值；紀錄包含來源排行。
- F8緊急停止、視窗焦點離開/被遮住/縮放時停止。啟動後偵測器會縮到工作列。
- 沿用GitHub軟體內更新與設定/紀錄保留。

首次使用：先設定表格六欄，再按「自動輪切設定」選擇三竹視窗並依序框選三個區域；勾選排行後先「測試輪切一次」，確認正確後「開始自動輪切」。切換與掃描期間滑鼠由偵測器使用。

已加入Windows模擬選單的點擊、切換標題及停止測試。尚未在使用者實際三竹版本驗證，可能需要調整選單字體、範圍及滑鼠滾輪行為。不是官方SDK/API串接，讀取設定頁數不保證涵蓋全部名單，不執行下單。
