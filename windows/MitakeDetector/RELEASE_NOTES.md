# 三竹盤中轉強偵測器 v0.3.8

- 新增預設開啟的本機自適應加速，記住經標題驗證的選單捲動路徑；後續直接到該段，再以 OCR 完整核對類目文字後選取。
- 經驗位置失效時清除並完整搜尋，視窗尺寸或框選區域改變時重新學習。切換後標題不符仍立即停止，不採用錯誤排行。
- 完整成功讀取後，每個排行的停留時間逐步縮短至最低1秒；缺值或空結果恢復原設定等待時間。可關閉自適應加速、清除操作經驗。
- 只在圖片像素完全一致時重用 OCR 結果，最多保留24張的文字辨識結果；行情畫面改變便重新辨識，讀取時間重新產生。
- 選取後提早核對標題，未完成時逐步延長等待；移除切換成功後額外的1.2秒等待。保留表格回頂與翻頁等待。
- 頂部任務列顯示經驗加速、回退搜尋、自適應倒數與 OCR 重用次數。
- 經驗僅包含各排行的搜尋段數與成功次數，不會自行修改程式或選股條件。實際速度受電腦效能、OCR與三竹反應影響。
