漲停板探測器-雷允澤製 v0.3.62

- 換筆電、解析度或視窗大小變更後，F8啟動自動核對目前視窗並重新定位表頭、資料列與下拉選單，不再因與舊尺寸不符而直接拒絕啟動；辨識不完整時保留進度，不使用舊座標盲點。
- 表頭增加同列六欄文字交叉核對，擴大搜尋至上方55%；以文字高度調整下拉框邊界，支援不同字體大小與DPI。普通辨識失敗後以重疊分區、放大及對比調整重新定位，座標轉回原圖。
- 新位置確認後儲存目前設備的配置與表頭快取。保留使用者原排行、篩選條件、每日資料庫與斷點輪次；當前排行保留已讀股票並重新核對位置，不沿用舊設備失效的滾輪距離。
- Windows啟動優先啟用Per-Monitor V2 DPI感知，舊系統回退至既有模式，避免實體擷取與點擊座標因縮放不一致；掃描中途調整視窗時仍先安全暫停，按F8重新定位接續。
- 保留頂部狀態列三角形折疊、語音與今日曾5/6清單。Windows合成中文表頭測試涵蓋1366×768、1920×1080、3840×2160，單元測試另涵蓋1024×768、2560×1440及不同字體比例；仍須實際三竹畫面確認。
