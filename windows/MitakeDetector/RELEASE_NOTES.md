# 三竹盤中轉強偵測器 v0.3.3

- 新增「一鍵自動設定」：尋找唯一的熱門排行視窗，自動辨識下拉框、展開選單、資料表與六個主要欄位，並實際驗證一次漲幅排行切換和股票讀取後儲存。
- 首次可在熱門排行視窗按F8，自動設定成功後直接開始五個排行輪切；再按F8停止。
- 支援名稱在股號左側，以及多個額外行情欄位同時顯示；以分欄OCR避免額外數字混入。
- 保留手動設定；辨識不完整或出現多個熱門排行視窗時停止，不猜位置。
- OCR仍可能漏讀或辨錯；尚未取得三竹官方資料介面，非全市場逐筆資料。
- 新增欄位中，日期、內外盤量、大單買賣超尚未用於提醒條件；本版讀取股號、名稱、成交、幅度%、成交量與週轉率。

- 新增真正的一鍵更新：按下後檢查新版，自動下載、驗證大小與SHA-256、啟動安裝並重開，不需再次按下載確認。保留設定與歷史資料，執行任務時先停止再更新。
