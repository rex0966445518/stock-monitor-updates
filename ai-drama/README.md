# AI 短劇搜搜 v0.3.1
獨立 Android App：com.ai.dramasearch。保留 v0.3 觀看紀錄及續看功能。專屬 ai-drama-v* 發布標籤，不使用共用庫的 releases/latest。
試用 APK 由 Actions artifact 提供，debug 簽章不保證能跨次覆蓋。正式版須設定專屬 DRAMA_KEYSTORE_B64、DRAMA_KEYSTORE_PASSWORD、DRAMA_KEY_ALIAS、DRAMA_KEY_PASSWORD，才以固定簽章發布。不得公開私鑰。GitHub Release 使用 --latest=false，不影響股票軟件。
全網搜尋後端尚未部署；使用既有合法公開搜尋入口或設定 API。外部影片播放時間需要手動記錄。
